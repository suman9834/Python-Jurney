## Data Types in Python
        Data types are the classification of data items. It represents the kind of value that tells what operations can be performed on a particular data. In Python, data types are used to define the operations possible on them and the storage method for each of them.
# Integer
    #Integer is a whole number without a decimal point. It can be positive, negative, or zero. In Python, we can define an integer variable by assigning a whole number to it. for example
age = 19


# string 
    #String is a sequence of characters enclosed in single quotes ('') or double quotes (""). In Python, we can define a string variable by assigning a sequence of characters to it.
# for example 
name = "suman"

# Float
    #Float is a number with a decimal point. It can be positive, negative, or zero. In Python, we can define a float variable by assigning a number with a decimal point to it. for example
roll = 4995599.5995

# Boolean
    #Boolean is a data type that can have one of two values: True or False. for example
    true_value = True
    false_value = False

# None
    None is a special data type that represents the absence of a value or a null value. In Python, we can define a variable with None by assigning None to it. for example
    no_value = None

# In Python, we can use the type() function to check the data type of a variable. The type() function returns the data type of the variable passed to it as an argument.


print(type(name)) # printing the  type of variable name

print(type(age)) # printing the type of variable age

print(type(roll)) # printing the type of variable roll
